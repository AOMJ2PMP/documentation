## Phase overview

| Phase | Weeks | Focus |
| :-- | :-- | :-- |
| Phase 1 Base | 1-4 | Aerobic base, movement patterns |
| Phase 2 Build | 5-8 | Volume, race-pace intervals |
| Phase 3 Race prep | 9-13 | Simulations, pacing |
| Phase 4 Taper | 14-16 | Reduce volume, stay sharp |

## Cycle-aware training

- **Day 1 of period:** Full rest (swap with rest day)
- **Days 2-3:** Light movement only
- **Days 4-5:** Ease back in at 70%
- **Follicular (days 6-14):** Power window - schedule hard sessions
- **Luteal (days 15-28):** Steady effort, zone 2, extra carbs/water
