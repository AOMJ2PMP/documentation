## **Phase 1：基础建设期（第 1–4 周）**

| 天 | 内容 | 细节 |
| :-- | :-- | :-- |
| 周一 | Zone 2 轻松跑 | 30 min → 每周加 5 min → 第 4 周 45 min，7.0–8.0 km/h |
| 周二 | 力量训练 | 上肢 \+ 核心（为站点打基础） |
| 周三 | 阈值间歇 | 热身 10 min → 4 组 × 5 min @ 8.5 km/h，休息 1 min → 放松 5 min |
| 周四 | 力量训练 | 下肢 \+ 功能性动作（深蹲、lunges、deadlift） |
| 周五 | Zone 2 长跑 | 40 min → 每周加 5 min → 第 4 周 55 min，6.5–7.5 km/h |
| 周六 | F45 Hyrox Foundation | 站点练习 \+ 混合训练 |
| **周日** | **完全休息** | 散步、拉伸都可以，不做任何训练 |

## **Phase 2：发展期（第 5–8 周）**

| 天 | 内容 | 细节 |
| :-- | :-- | :-- |
| 周一 | Zone 2 轻松跑 | 45–50 min，7.0–8.0 km/h |
| 周二 | 力量训练 | 上肢 \+ 核心 |
| 周三 | 阈值训练（A/B 周交替） | **A 周：** 5 组 × 5 min @ 8.5–9.0 km/h，休息 1 min |
|  |  | **B 周：** 持续阈值跑 20 min → 逐步加到 30 min @ 8.5 km/h |
| 周四 | 力量训练 | 下肢 \+ 功能性 |
| 周五 | Compromised running | 20 深蹲 → 20 步 lunge → 1km @ 8.5 km/h → 休息 2 min → 重复 3 组 |
| 周六 | F45 Hyrox Foundation |  |
| **周日** | **完全休息** |  |

注意这个阶段长跑被去掉了，因为你的 Zone 2 基础已经在 Phase 1 建好了（能跑 45–50 分钟），周一的 Zone 2 跑维持这个水平就够。周五换成了 compromised running，开始接近比赛节奏。如果你觉得一周少了一次纯 Zone 2，可以在周四力量训练后加 20 分钟跑步机 Zone 2 作为收尾。

## **Phase 3：比赛专项期（第 9–13 周）**

| 天 | 内容 | 细节 |
| :-- | :-- | :-- |
| 周一 | Zone 2 轻松跑 | 45–50 min，7.5–8.0 km/h（同样心率，配速应该比 Phase 1 快了） |
| 周二 | 力量训练 | 开始偏向站点专项（sled 替代、wall ball 动作模式、farmers carry） |
| 周三 | 交替：阈值 / Norwegian 4x4 | **A 周：** 持续阈值跑 25–30 min @ 9.0 km/h |
|  |  | **B 周：** Norwegian 4x4（4 × 4 min @ 9.5–10.5 km/h，恢复 3 min） |
| 周四 | 力量训练 | 同上 |
| 周五 | Compromised running（进阶） | 模拟 2–3 站完整循环：SkiErg 替代 → 1km run → wall balls → 1km run → lunges → 1km run |
| 周六 | F45 Hyrox Foundation |  |
| **周日** | **完全休息** |  |

这个阶段如果能安排 1–2 次去有真实 sled 和 SkiErg 的场馆，放在周五或周六替换一次。

| :-- | :-- | :-- |

| 周四 | 休息或散步 |  |
| 周五 | Zone 2 轻松跑 | 25–30 min |
| 周六 | F45（最后一次，轻松做） |  |
| **周日** | **完全休息** |  |
